# 📊 Excel Data Analytics Portfolio

Welcome to my Excel Data Analytics Portfolio! This repository showcases my advanced skills in Microsoft Excel, ranging from foundational spreadsheet functions to advanced data modeling and dynamic dashboard creation.

## 🗂️ Repository Structure

This repository is logically organized into modules and comprehensive projects:

- **`1_Spreadsheets_Intro` & `2_Formulas_Functions`**: Core concepts and essential formulas (XLOOKUP, INDEX/MATCH, Logical & Text functions).
- **`3_Charts_Graphs`**: Data visualization using standard and advanced charts, including sparklines.
- **`4_Spreadsheets_Advanced`**: Advanced formatting, data validation, and working with Excel Tables.
- **`5_Pivot_Tables`**: Summarizing large datasets and creating dynamic Pivot Charts.
- **`6_Advanced_Data_Analysis`**: What-If Analysis, Data Tables, and using the Analysis ToolPak.
- **`7_Power_Query`**: Advanced ETL (Extract, Transform, Load) processes. Cleaning dirty data, merging queries, and introduction to the M language.
- **`8_Power_Pivot`**: Advanced data modeling, relationships between tables, and writing DAX (Data Analysis Expressions) formulas.
- **`0_Resources`**: Datasets (including a massive 3-million row dataset), images, and problem/solution workbooks.
